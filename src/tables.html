The standard normal table

The entries give left area P(Z<z), rounded to four decimals. Round z to two decimals. Negative rows use a negative hundredths digit too: row −1.6, column .04 means −1.64.

For z beyond ±3.49, the course treats left area as essentially 0 or 1. For inverse lookups, choose the closest four-decimal entry. Ties use the midpoint z, such as .9500 → 1.645.

The t table

Columns show upper-tail area. For a confidence interval use (1−C)/2. For a test, use column α (one-sided) or α/2 (two-sided). For a p-value, use tcdf on the TI-84 or T.DIST in Excel; the table can only bracket it. For unlisted df, use the next smaller row. The bottom row gives z*, the critical value for a proportion.

Which row and column? It depends on the method. The method guide walks you from the problem to the right interval or test, and tells you where its critical value is.

Table values are rounded to three decimals. Software checks use actual df and full precision.

Course conventions. Quartiles exclude the median from both halves when n is odd. Use Sx for sample SD, σx for a probability distribution. Use no continuity correction in the normal approximation to the binomial. Proportion CI counts use p̂; test counts and SE use p₀. Always round a planned n up.
