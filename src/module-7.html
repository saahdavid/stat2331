1. Estimate a fixed population parameter

A point estimate is a single best guess; a confidence interval adds a margin to describe precision. For a proportion, estimate p with p̂; for a mean, estimate μ with x̄. A standard error (SE) estimates the SD of a statistic when population variability is unknown.

  • Construct intervals for p and μ, checking their conditions.
  • Find critical values from the normal and t tables.
  • Interpret confidence correctly and recover a margin from endpoints.
  • Plan n for a desired margin of error.
\text{confidence interval}=\text{point estimate}\pm\text{margin of error}

The confidence level C describes the long-run capture rate of the method. Its error rate is α=1−C. The realized interval and the population parameter are fixed once the data are collected; we do not assign a 95% probability to a fixed parameter falling in that one interval.

Not sure which method a problem needs? Use the method guide: three questions point to the right interval, test, or sample-size formula, and the drill gives you practice recognizing each one.

2. Confidence interval for p

SE_{\hat p}=\sqrt{\frac{\hat p(1-\hat p)}n},\quad\hat p\pm z^*SE_{\hat p}

Conditions: random data, approximate independence, at least 10 observed successes and 10 observed failures. Use p̂ in the interval SE because p is unknown. Critical values: 80% → 1.282; 90% → 1.645; 95% → 1.960; 99% → 2.576. Each tail has area (1−C)/2.

Worked example

Does the sports drink improve energy?

An SRS of 150 volunteers includes 72 who report improvement. Construct a 95% CI.

  1. Parameter: true proportion of people who notice improved energy.
  2. p̂=72/150=.48. There are 72 successes and 78 failures, so both counts pass.
  3. SE=√[.48(.52)/150]=.04079…
  4. z*=1.960; margin=1.960(.04079…)=.07995…
  5. CI=.48±.07995…=(.4000,.5600), rounded to (.40,.56).
  6. We are 95% confident the true proportion who notice improved energy lies between .40 and .56.
TI-84STAT → TESTS → 1-PropZInt. x=72, n=150, C-Level=.95 → Calculate.
Excel=72/150-1.96*SQRT((72/150)*(1-72/150)/150). Replace minus by plus for the upper bound.

The manufacturer’s target .35 is below this interval. Within this analysis, all plausible values exceed .35. Design and representativeness still matter when deciding where the result generalizes.

Use the right counts. For a proportion CI, check successes and failures in the observed sample. For a proportion test in Module 8, use expected counts under p₀ instead.
Worked example

90% CI

In an SRS of 1820 people, 364 agreed with a statement. \hat p = 0.2; 364 successes and 1456 failures. 0.2 \pm 1.645\sqrt{0.2(0.8)/1820} = 0.2 \pm 0.015 = (0.185,\ 0.215).

Common mistakes. Using z^* for the wrong confidence level. Leaving n out of the square root. Rounding \hat p or the SE too early; store them instead.

3. Why t replaces z for a mean

Population σ is usually unknown, so estimate it with sample s. This extra uncertainty leads to the t distribution for the standardized sample mean under normal sampling. The sample mean itself is not “t-distributed”; the standardized statistic is. t is centered at zero, has heavier tails than normal, and approaches normal as degrees of freedom increase.

SE_{\bar x}=\frac{s}{\sqrt n},\quad T=\frac{\bar x-\mu}{s/\sqrt n},\quad df=n-1

To read t*: calculate df, choose the next smaller listed df if needed, and use upper-tail area (1−C)/2. The t table has df 1–30, 40, 50, 60, 80, 100, 1000. Software uses actual df and may give a slightly smaller critical value.

Worked example

A 99% interval for a mean facial ratio

n=40, x̄=1.524, s=.106. The data show no extreme skew or extreme outliers.

  1. SE=.106/√40=.01676…; actual df=39.
  2. For the hand table, use df=30. Upper-tail area=.005 gives t*=2.750.
  3. Margin=2.750(.01676…)=.04609…
  4. Table CI=1.524±.04609…=(1.478,1.570), rounded.
  5. The lecture’s software calculation uses actual df=39, t*=2.708, giving (1.479,1.569). Both are shown so you can distinguish the conservative table rule from the exact check.
TI-84TInterval → Stats; x̄=1.524, Sx=.106, n=40, C-Level=.99. For table-row t*: invT(.995,30).
ExcelExact upper bound: =1.524+T.INV(0.995,39)*0.106/SQRT(40). Use df 30 for the table check.

4. Confidence interval for μ

\bar x\pm t^*\frac{s}{\sqrt n}

Conditions: randomly gathered, approximately independent data, and no extreme skew or extreme outliers. Small departures from normality can be acceptable; extreme observations are a concern because x̄ and s are not resistant. Inspect the distribution rather than declaring every large sample automatically safe.

Worked example

Mean percentage of dietary fat

n=165, x̄=35.294, s=6.981. Find a 95% CI.

  1. SE=6.981/√165=.54346…
  2. Actual df=164; the hand table uses df=100, t*=1.984.
  3. Table margin≈1.078; CI≈(34.216,36.372).
  4. Exact software t*=1.9745… gives the lecture interval (34.221,36.367).
  5. State the conclusion about the population mean dietary fat percentage, not individual nurses’ diets.
TI-84STAT → TESTS → TInterval → Stats. Enter x̄, Sx, n, and .95.
Excel=35.294-T.INV(0.975,164)*6.981/SQRT(165); use plus for the upper bound.

5. Margin, width, and interpretation

\text{estimate}=\frac{L+U}{2},\quad m=\frac{U-L}{2},\quad\text{width}=2m

For (.40,.56), the center is .48, width .16, and margin .08. Higher confidence requires a wider interval. Larger n narrows it, with SE proportional to 1/√n. More variable observations make it wider. Do not reduce confidence after looking at results just to produce a desired conclusion.

TI-84Center: (.40+.56)/2. Margin: (.56−.40)/2.
Excel=AVERAGE(0.4,0.56); =(0.56-0.4)/2.

“95% confident” means that about 95% of intervals constructed by this procedure over repeated random samples capture the fixed parameter. It does not mean 95% of individual observations lie in the interval or 95% of samples have the same estimate.

Wrong interpretations to avoid. "There is a 95% probability that p is in (0.40, 0.56)." "95% of the data fall in the interval." "95% of sample proportions fall in this interval." The interval is about the parameter, and the 95% is about the method.

6. Plan precision before collecting data

n_p=\left\lceil\frac{(z^*)^2\hat p(1-\hat p)}{m^2}\right\rceil,\qquad n_\mu\approx\left\lceil\frac{4s^2}{m^2}\right\rceil\;\text{at 95\%}

For p, use a pilot p̂ or the conservative .5 if no estimate is available. Use m as a proportion (.05 for five percentage points). For μ, the course’s 95% planning approximation uses t*≈2; obtain s from a pilot study if necessary. Always round n up.

Worked example

Smaller margins need more observations

  1. Verve: p̂=.48, 95% confidence, m=.05. n≥1.96²(.48)(.52)/.05²=383.531… → 384.
  2. Nurses: s=6.981, 95% confidence, m=.5. n≥4(6.981)²/.5²=779.75… → 780.
  3. Rounding down would fail the precision target. The second formula is a planning approximation, not an exact small-sample guarantee.
TI-84Calculate each expression, inspect its fractional part, and round up to the next integer.
Excel=ROUNDUP(1.96^2*0.48*0.52/0.05^2,0); =ROUNDUP(4*6.981^2/0.5^2,0).
